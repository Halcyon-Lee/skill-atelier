# 视频风格创作平台：首期设计

日期：2026-10-24
状态：供用户确认；尚未实现。

## 已确定的产品方向

由 Skill 收录站转向视频风格创作平台。用户浏览视频样片，选择一种风格，输入自己的脚本，由后台对应的 Skill 和 Agent 执行制作并交付成片。第一期采用官方精选模式，先验证 3–5 种风格，不开放用户发布制作流程。首批样片来自用户指定的 Lemo-Opuscar。

已有管理员昵称“带熊猫去竹林”、登录方式和固定邀请码 Leadnext2026 保持。既有 35 条 GitHub Skill 数据保留，不再作为首页主要内容。

- 官方仓库：https://github.com/lemomo-ai/lemo-opuscar

核对时画廊有 59 种风格、11 个分类。每种风格配样片与 STYLE.md。其技术路线主要是 Agent 生成 Canvas/WebGL 等绘制代码，通过浏览器逐帧渲染，再合成配音、音乐和字幕；不能把样片地址当作任意脚本的生成接口。作者对生成时间给出的参考为 30–60 分钟，平台自己的等待时间和成本必须实测。

代码与文档为 MIT，演示视频和静帧按 CC BY 4.0 使用，署名 LemoLab，链接原仓库，修改时注明。演示中的第三方素材保留各自许可，应逐个检查所选样片的 CREDITS。项目明确排除三条声音轨：Game Show Flat、Paper-cut Lightbox、Broadcast News Package 的特定声音；首期不选择这三种作为首页素材。本站收录者与原作者分别展示，避免把转载样片标成本站生成作品。

## 用户界面与流程

1. 首页公开展示精选视频样片，沿用现有深色与薄荷绿视觉。减少介绍性大区块，让视频占据主要空间；封面优先加载，预览按交互加载，不同时播放全部视频。卡片显示风格名称、适用内容、样片时长与收录者，提供来源信息。
2. 点击卡片进入风格详情与创作页，大样片与脚本输入并列。首期固定 30 秒、1920×1080 横屏、24 fps、中文，使用每个风格预先配置并验证的配音与配乐设置。脚本须为 10–2000 字符。用户只填脚本即可提交；更多时长、比例和声音选项留待后续扩展。
3. 浏览样片不要求登录；提交生成前登录或使用固定邀请码注册，并保留当前风格和脚本草稿。现有账号系统复用，补充登录后的返回路径。
4. 生成任务独立展示：排队、编排、渲染、合成、完成或失败。展示真实阶段和错误，不用定时器伪造完成进度。离开页面后仍能在“我的作品”查看。
5. 成功任务提供实际生成的视频预览与下载；失败任务保留脚本并允许重试。重试创建关联的新任务，不覆盖既有成片。

导航以“发现风格”“我的作品”“收藏”为主。原 Skill 管理保留在管理入口，不在主流程里要求用户理解 Skill、模型和运行环境。

## 生成系统

网站进程负责权限、参数验证、任务记录与结果查询。独立 worker 负责领取任务，在每个任务独立的工作目录中运行对应 Agent、固定版本的 Skill 与依赖。首期单 worker、同时运行一项任务，每位用户最多保留一项未结束任务，单项任务 90 分钟超时。领取任务后持续更新租约；worker 重启后将失去租约的执行中任务标记为可重试失败，不自动重复消耗生成费用。先验证领取与失败处理，再扩展并发。

风格配置记录：来源与版本、封面/样片地址、风格文档、允许的生成规格、执行适配器、可用状态。任务记录：用户、风格与版本快照、脚本、规格、当前阶段、执行租约、开始/结束时间、结果文件与错误说明。任务重新领取必须检查租约，避免重复执行。

Agent 生成绘制代码、时间线与声音素材，渲染工具生成画面，再合成最终 MP4。运行凭据只放在服务端配置；用户输入作为任务数据传入，不拼接为 shell 命令。结果文件经所属用户或管理员鉴权后提供。服务重启不把未完成任务误报为成功。

本机已检测到 Claude CLI、ffmpeg、Python、uv 和 Docker 的可执行文件；尚未确认 Agent 认证、运行隔离、声音组件和完整渲染依赖可用。依赖存在不代表生产运行环境已就绪。

## 实施顺序与验收

第一步：更换首页与主导航，接入五种样片及来源信息，完成风格页和脚本草稿；未验证的风格明确显示暂未开放生成，不展示虚构结果。

第二步：优先验证瑞士动态排版的一条真实出片流程，连接脚本提交、任务持久化、独立 worker、结果预览与下载。以一份新脚本生成新视频作为验收，不以播放原站样片代替。

第三步：逐个适配其余候选风格，分别做真实脚本验收后开放生成。当前阶段不开发创作者上传、交易分成或复杂视频编辑器。

测试覆盖：访客浏览与登录返回、脚本和规格校验、任务归属权限、重复提交、任务重启恢复、失败重试、真实产物与样片区分。至少验证一种风格的实际 MP4 可解码且包含本次脚本内容；界面验证覆盖桌面和移动端。时间和费用仅展示实测或服务端确认的数据。
