# ATELIER 社区 UI：NEAR 视觉方向

用户已选择社区方案 A，并指定 https://near.org/ 为 Web3 视觉参考。本设计替代先前方案中的暖白底、橙色点缀，沿用已确定的 Skill 内容结构。

## 视觉与体验

- 黑色页面、近黑卡片、白色正文、薄荷绿主色；细线分区，少量柔和绿光与几何图形。
- 用现有 Geist 无衬线字体构建主标题和正文；标题清晰有力，正文 16px，标签与次要文字最低 12px。
- 主按钮为薄荷绿底深色字；次按钮透明描边。输入框、菜单、提示、错误、焦点分别有明确状态，错误保留独立的语义颜色。
- 动效仅用于短暂交互反馈，尊重 reduced-motion。几何装饰用现有 SVG/CSS 实现。
- 采用原有语义 token，统一更新颜色、字重、圆角、控件高度和间距，避免叠加第二套主题系统。

## 页面

1. 邀请入口：直接表达“发现好用的 AI Skills”，以简洁大标题、双入口与几何视觉展示社区定位；邀请码表单继续可用。
2. 登录／注册：统一黑绿主题。左侧以中文产品说明、场景与案例示意表达价值；右侧聚焦填写与提交。
3. 技能库：减少标题和精选区的高度，把搜索置于核心位置；分类可换行，列表卡片重点展示名称、描述、使用场景。
4. 详情：名称与简短描述、使用场景、输入到输出的实际案例、截图、完整文档层级分明；保留安装与收藏操作。
5. 发布、收藏、资料与管理页：沿用统一主题，改善文字大小、字段分组、操作尺寸和阅读对比度。

## 范围与验证

沿用现有注册／登录、邀请码、权限、技能保存和搜索流程，不加入链上账户或交易业务。保留 ATELIER 名称和已有数据。

运行类型检查、Lint、现有业务测试、生产构建；计算主要前景／背景的对比度，检查 375/768/1024/1440 宽度下的栅格、长文字和控件规则。浏览器若仍受本地 URL 策略限制，明确记录视觉验证的限制，不使用绕过方案。

## 参考使用记录

阅读了 UI UX Pro Max 的 SKILL.md 和 quick-reference.md，并运行其本地检索。Minimalism & Swiss Style 匹配到黑白、高对比、无衬线和网格布局原则；颜色、字号和页面安排结合实际 NEAR 截图与本项目用途确定。两次自动设计系统输出的产品匹配不准确，未采用或持久化。
